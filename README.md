# 🛍️ Shop — فروشگاه اینترنتی کامل و ماژولار

فروشگاه اینترنتی کامل شبیه دیجی‌کالا، ساخته‌شده با **.NET 10 (LTS)** و معماری تمیز و ماژولار — قابل استفاده به‌عنوان پایه برای **هر فروشگاه آنلاین** بدون تغییر در هستهٔ کد.

## ✨ امکانات

### 🏪 فروشگاه (Storefront)
- صفحه اصلی با اسلایدر، **پیشنهاد شگفت‌انگیز با شمارش معکوس**، منتخب ادیتور، پرفروش‌ترین‌ها و جدیدترین‌ها
- لیست محصولات با **فیلتر** (دسته، قیمت، موجودی، تخفیف) و **مرتب‌سازی** (جدیدترین، پرفروش، ارزان‌ترین،...)
- صفحه محصول با گالری، امتیاز، نظرات، محصولات مشابه و جستجوی زنده (AJAX)
- **سبد خرید دیتابیسی** برای کاربر عضو *و* مهمان (با ادغام خودکار هنگام ورود)
- **رزرو موجودی مثل دیجی‌کالا**: شروع تسویه → رزرو اتمیک با تایمر قابل‌تنظیم → پرداخت موفق → کسر از موجودی؛ انقضا → آزادسازی خودکار توسط Background Job
- درگاه پرداخت شبیه‌سازی‌شده + **اینترفیس آماده `IPaymentGateway`** برای اتصال هر درگاه واقعی (Strategy + Factory با Keyed DI)
- کد تخفیف (درصدی با سقف، حداقل خرید، محدودیت تعداد و انقضا)
- پنل کاربر: سفارش‌ها، جزئیات سفارش، لغو با بازگشت خودکار موجودی، علاقه‌مندی‌ها، پروفایل، تغییر رمز
- وبلاگ با نظر، تماس با ما، سوالات متداول، قوانین، خبرنامه
- **PWA حرفه‌ای**: نصب روی گوشی (A2HS)، Service Worker هوشمند، صفحه آفلاین، آیکون و Manifest
- کاملاً **ریسپانسیو و RTL** با فونت وزیرمتن

### 🛠 پنل مدیریت (فوق‌سبک، بدون فریمورک)
- داشبورد آماری با نمودار ۷ روز اخیر و هشدار موجودی کم
- CRUD کامل: محصولات (با گالری و اسلاگ خودکار)، دسته‌بندی درختی، اسلایدر، وبلاگ، کد تخفیف
- مدیریت سفارش‌ها با تغییر وضعیت (لغو = بازگشت خودکار موجودی)
- تأیید/رد نظرات محصولات و وبلاگ، کاربران (فعال/غیرفعال)، پیام‌ها، خبرنامه
- **تنظیمات فروشگاه**: نام، رنگ، هزینه ارسال، آستانه ارسال رایگان، **مدت رزرو موجودی**، سقف خرید هر کالا و... — همه از پنل!

## 🏗 معماری (SOLID + Clean Code)

```
src/
├── Shop.Domain/          ← اینتیتی‌ها + Enumها (بدون وابستگی)
├── Shop.Shared/          ← تاریخ شمسی، اسلاگ‌ساز، فرمت قیمت
├── Shop.Application/     ← DTOها + اینترفیس سرویس‌ها
├── Shop.Infrastructure/  ← EF Core 10 + سرویس‌ها + Seeder + درگاه پرداخت + Background Job
└── Shop.Presentation/    ← MVC + Area ادمین + PWA + Views
```

**الگوها**: Strategy (درگاه پرداخت) · Factory (Keyed DI) · Decorator (کش دسته/اسلایدر) · Result (خروجی عملیات) · UoW (تراکنش اتمیک) · BackgroundService (آزادسازی رزرو)

**پرفورمنس**: Projection به DTO · `AsNoTracking` سراسری · OutputCache · ResponseCompression (Brotli) · ایندکس‌های هدفمند · آپدیت‌های اتمیک SQL · بدون N+1

**امنیت**: Antiforgery روی همه POSTها · Rate-friendly Identity با Lockout · اعتبارسنجی سمت سرور · هش پسورد Identity · بدون اطلاعات حساس در کلاینت

## 🚀 اجرا

```bash
# ۱) دیتابیس
docker compose up -d postgres

# ۲) مایگریشن + Seed (محصولات تستی، ادمین، دسته‌ها، وبلاگ و...)
dotnet ef database update -p src/Shop.Infrastructure -s src/Shop.Presentation

# ۳) اجرا
dotnet run --project src/Shop.Presentation
```

سپس: **http://localhost:5200**
